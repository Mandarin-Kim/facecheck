# 페이스체크 v2 (시험판)

v1(운영)과 완전히 분리된 시험판입니다. 서버·어드민과 연결하지 않으며, 측정 결과는 **이 휴대폰 브라우저 안(IndexedDB)** 에만 저장됩니다.

## 여는 방법
| 주소 | 용도 |
|---|---|
| `https://mandarin-kim.github.io/facecheck/v2/` | 실제 카메라·마이크로 측정 |
| `…/v2/?sim=1` | 시뮬레이션 — 카메라 없이 가짜 데이터로 전체 흐름 확인 (결과 화면에 "시뮬레이션" 표시) |
| `…/v2/?dev=1` | 개발자 패널 — 화면 아래에 상태·프레임 수·얼굴 위치 등 실시간 표시 |
| `…/v2/?sim=1&dev=1` | 둘 다 |

## 구조 (명세서 A–K 대응)
- **미션(M01–M08) → 수집(Capture) → 특징(Feature) → 평가(Assessment) → 근거(Evidence)**
- 수집 1번으로 여러 평가를 만듭니다 (예: 정면 보기 1회 → 심박·맥박변동·호흡·눈깜빡임·피부 등).
- 수집 데이터는 만들어진 뒤 바꿀 수 없고(동결 + 해시), 모든 결과에 "어떤 수집·어떤 규칙 버전으로 계산했는지"가 붙습니다.
- 결과 상태 4가지: **결과 제공 / 참고용 / 연구 중 / 측정 불가**. 검증되지 않은 모델(스트레스 점수, 뇌 나이)은 숨김(held).
- 실패하면 이유(Q-001…Q-015)와 함께 **그 미션만 다시** 할 수 있습니다.

## 결과값 신뢰성 검토 (2026-10-20, 자세한 표: 페이스체크_v2_신뢰성검토.xlsx)
정답을 미리 정한 합성 데이터로 "맞는 값을 내는가"와 "못 믿을 때 값을 숨기는가"를 확인했습니다.
- 심박: 45 bpm을 90으로 잘못 읽던 문제 수정. 카메라 처리 경로 48회 중 45회 표시, 최대 오차 1.2 bpm, 틀린 값 0
- PRV(스트레스 원자료): 수정 전엔 표시한 값의 58~80%가 틀림(평균 +62% 과대) → 잡음을 스스로 재서 믿을 만할 때만 표시(표시 시 평균 오차 8%, 틀림 0). 실제 폰에선 대부분 "측정 불가"가 될 가능성
- 눈 깜빡임: 느린 폰·떨림에서 ±15~27% 틀리던 것 수정, 표시 시 오차 1.2%
- 반응 시간: 손 뗄 때가 아니라 닿는 순간, 화면이 그려진 프레임 기준으로 측정(오차 0.5 ms 이하)
- Framingham·STOP-Bang: 공개 구현·전체 조합과 일치
- 자동 시험: `node tests/engine.test.js` (31개), `node tests/reliability.js out.json` (신뢰성 대량 시험)

## 알려진 한계
- 자동 시험은 가상 브라우저와 합성 영상으로만 했습니다. 실제 피부색·조명·기기별 정확도는 아직 검증 전입니다.
- 결막(빈혈 관련)·손톱·목 판정은 규칙 기반 시험 구현이며 기준값이 검증되지 않아 "연구 중/참고용"으로만 표시합니다.
- 스트레스 점수·뇌 나이는 검증 근거가 없어 결과에 표시하지 않습니다 (계산 흔적만 내부 기록).
- 신뢰성 검토는 합성 데이터 기준입니다. 실제 사람·기기에서 기준 기기(맥박계·심전도)와 비교하는 파일럿이 필요합니다.
- 전신(M06)은 기기 성능이 낮으면 인식이 느릴 수 있습니다.
